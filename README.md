# Saudi Heroes · أبطال السعودية

A proposed national project creating characters that represent Saudi children and introduce Saudi culture to the world, inspired by the Kingdom's 13 regions. This bilingual website, with 13 interactive stories and an AlUla adventure, is the characters' first application.
Graduation project, Digital Media Fellowship. An independent project, not affiliated with any government body.

مشروع وطني مقترح يبتكر شخصيات تمثّل الطفل السعودي وتعرّف العالم بثقافتنا، مستوحاة من مناطق المملكة الـ١٣. الموقع ثنائي اللغة، بقصصه التفاعلية الـ١٣ ومغامرة العُلا، أول تطبيق لهذه الشخصيات.
مشروع تخرج في زمالة الإعلام الرقمي. مشروع مستقل، غير تابع لأي جهة حكومية.
